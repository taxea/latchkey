The message uses the IRS seal and a refund amount that sounds plausible ($1,247.36). The link opens a form asking for everything needed to file a fraudulent return in your name: Social Security number, date of birth, driver's license and bank account "for direct deposit."

The IRS initiates contact by mail. It does not text, and it does not email about refunds. Forward the message to phishing@irs.gov and delete it. If you entered details, get an [IRS Identity Protection PIN](/protect/identity-theft/) today so nobody can file as you. [The full record on IRS impersonation.](/scams/irs-impersonation-scam/)
