term: Substitute for Return
definition: "A Substitute for Return (SFR) is a tax return the IRS files on your behalf when you have not filed, using only the income reported to it and no deductions or credits."
example: "The IRS assessing tax on a self-employed person's full gross receipts with no business expenses deducted."
whyItMatters: "An SFR almost always overstates what you owe. Filing the real return replaces it and the balance is recalculated."
