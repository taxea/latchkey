term: Remote access software
definition: "Remote access software lets another person see and control your computer over the internet; legitimate for IT support, and the main tool of tech-support scams."
example: "AnyDesk, TeamViewer or UltraViewer installed at the request of a \"Microsoft technician.\""
whyItMatters: "Never install remote-access software at the request of someone who contacted you. If it is already installed and you did not choose it, disconnect from the internet and uninstall it."
